### B. Sub-Segments for Segment 2 (Prerequisites)
**MANDATORY**: Break Segment 2 into sub-segments, one for each major prerequisite concept.

Each sub-segment MUST have:

### 2. Narration Script Writing

CRITICAL RULES for every segment:

**Rule 1: Concrete Examples First**
- ALWAYS start with a specific, concrete example
- Use the SAME example throughout the video for consistency
- Example: "Let's translate 'The cat sat on the mat' to French..."

**Rule 2: Simple-to-Complex Layering**
- Start with the simplest possible explanation (like explaining to a 12-year-old)
- Use real-world analogies ("Think of attention like a spotlight...")
- THEN add technical details
- Never assume the viewer knows jargon

**Rule 3: Show, Don't Tell**
- Instead of: "The encoder processes the input"
- Say: "The encoder takes our sentence 'The cat sat' and converts each word into a list of numbers"

**Rule 4: Explain WHY, Not Just WHAT**
- After explaining what something does, always say WHY it's designed that way
- "We do this because..."
- "This solves the problem of..."

**Rule 5: Simplify Mathematics from KG**
- If the KG mentions mathematical formulas or operations, you MUST explain them in the narration
- Start with the INTUITION: "What this formula does is..."
- Then concrete example: "For our sentence 'The cat sat', this means..."
- Then the actual operation if needed: "Mathematically, we're computing..."
- Example: Instead of just "scaled dot-product attention", say "We compare how related each word is to every other word by computing similarity scores, then we scale them down so they don't get too large..."

Write complete, word-for-word scripts as you would speak them:
- Use conversational, natural language ("Let's see..." "Notice how..." "Here's the cool part...")
- Include transitions between ideas ("Now that we understand X, let's look at Y")
- Use analogies and examples liberally
- Build suspense and curiosity ("But there's a problem..." "Here's where it gets clever...")
- Speak directly to the viewer ("Imagine you're..." "Think about...")
- Pace appropriately - don't rush complex ideas

**Example Good Narration:**
```
"Let's say we're translating the sentence: 'The cat sat on the mat.' Now, when we get to 
the word 'sat', our model needs to figure out WHO did the sitting. Was it the cat? The mat? 
This is where attention comes in. Think of it like a spotlight - it can shine brightly on 
'cat' when we're processing 'sat', telling the model: hey, these two words are connected! 
The attention mechanism learns to point this spotlight automatically. So for our sentence, 
it would learn to connect 'cat' with 'sat' strongly, but maybe connect 'mat' with 'sat' 
less strongly. That's the basic idea - attention helps words find related words."
```

### 4. Narrative Strategies

**"problem_to_solution"**: Start with problem → Show limitations of existing approaches → Introduce new solution
- Best for papers that clearly address a specific limitation

**"building_blocks"**: Introduce components one by one → Show how they connect → Reveal full system
- Best for papers with clear modular architecture

**"guided_tour"**: Walk through the data flow step by step → Highlight innovations along the way
- Best for papers with novel processing pipelines

Choose the strategy that best fits the paper's structure.
