## Understanding the Specification

### Shapes (scene.shapes)

Each shape has:
- `shape_id`: Variable name to use
- `shape_type`: Type descriptor (circle, text, equation, rectangle, arrow, etc.)
- `content`: Text or LaTeX formula if applicable
- `position`: Where to place it (center, left, top_right, etc.)
- `color`: Color to use
- `scale`: Scale factor
- `represents`: What it conceptually means (for your understanding)

**Your job**: Look at the RAG examples to find how to create these shape types in Manim.

Example:
```
Shape spec: {"shape_type": "circle", "color": "blue", "position": "center"}
→ Study examples to learn: use Circle()
→ Generate: circle = Circle(color=BLUE).move_to(ORIGIN)
```

### Animations (scene.animations)

Each animation has:
- `animation_id`: For reference
- `animation_type`: Type descriptor (create, write, fade_in, fade_out, transform, etc.)
- `target_shape_ids`: Which shapes to animate
- `duration`: How long the animation should take
- `description`: What it accomplishes

**Your job**: Look at the RAG examples to find the appropriate Manim animation classes.

Example:
```
Animation spec: {"animation_type": "fade_in", "target_shape_ids": ["circle"], "duration": 1.0}
→ Study examples to learn: use FadeIn()
→ Generate: self.play(FadeIn(circle), run_time=1.0)
```

### Math Animations (scene.math_animations)

These are more complex, involving mathematical formulas:
- `operation_type`: matrix_multiply, dot_product, attention_compute, etc.
- `input_formulas`: LaTeX formulas for inputs
- `output_formula`: LaTeX formula for result
- `visualization_style`: step_by_step, simultaneous, etc.
- `show_intermediate_steps`: Whether to show intermediates

**Your job**: Create MathTex objects for formulas and animate transformations.

## Position Mapping Reference

Based on the examples, common position strings map to:
- "center" → ORIGIN
- "left" → LEFT * 3 or LEFT * 2
- "right" → RIGHT * 3 or RIGHT * 2
- "top" → UP * 2
- "bottom" → DOWN * 2
- "top_left" → UP * 2 + LEFT * 3
- Use `.next_to()`, `.to_edge()`, `.shift()` for relative positioning

## Color Mapping Reference

Common colors in Manim (check examples for exact usage):
- WHITE, BLACK, GRAY, LIGHT_GRAY, DARK_GRAY
- RED, GREEN, BLUE, YELLOW, ORANGE, PURPLE, PINK
- Use color constants directly (e.g., `color=BLUE` not `color="blue"`)

## Common Patterns (Learn from Examples)

### Creating Basic Shapes
```python
# Text
text = Text("Hello World")

# Equation
equation = MathTex(r"E = mc^2")

# Shapes
circle = Circle(radius=1.0, color=BLUE)
rectangle = Rectangle(width=3, height=2)

# Arrows
arrow = Arrow(start=LEFT, end=RIGHT)
```

### Positioning
```python
# Absolute
obj.move_to(UP * 2 + LEFT * 3)
obj.to_edge(LEFT)

# Relative
obj2.next_to(obj1, DOWN, buff=0.5)
obj3.shift(RIGHT * 2)
```

### Animations
```python
# Creation
self.play(Create(shape))
self.play(DrawBorderThenFill(shape))

# Writing
self.play(Write(text))

# Fading
self.play(FadeIn(obj))
self.play(FadeOut(obj))

# Transforming
self.play(Transform(obj1, obj2))
self.play(ReplacementTransform(obj1, obj2))

# Moving
self.play(obj.animate.shift(RIGHT))
self.play(obj.animate.scale(2))

# Highlighting
self.play(Indicate(obj))
self.play(Circumscribe(obj))
```

The `code` field should contain valid Python code that:
1. Defines a Scene subclass
2. Implements construct() method
3. Creates all shapes
4. Executes all animations
5. Is ready to run with `manim -pql file.py ClassName`
