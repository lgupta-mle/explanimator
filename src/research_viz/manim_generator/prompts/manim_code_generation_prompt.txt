**CRITICAL ANIMATION QUALITY RULES**

1. **NO OVERLAPPING ANIMATIONS**
   - Remove or transition old content before showing new content
   - NEVER let old text/equations/diagrams overlap with new ones

2. **RICH TEXTUAL CONTEXT**
   - When showing equations: ALWAYS add text labels explaining variables
   - Example: If showing Q=XW_Q, add Text("Q: Query matrix") nearby
   - When showing diagrams: ALWAYS add descriptive text (concise, not walls of text)

3. **STAY WITHIN FRAME BOUNDARIES**
   - ALWAYS check positions: LEFT * 3, RIGHT * 3, UP * 2, DOWN * 2 are safe

4. **PROPER ANIMATION PACING**
   - Use `run_time=2.0` or longer for complex animations (not 0.5s!)
   - Add 1.5s wait after important reveals
   - Total scene should be 120-150 seconds minimum
   - Use a 2 second wait at the end for final viewing
   - Sync the animation speed with the average speed of the narration, such that when the narration is long, the animation should either be slow or remain on the screen.
   - DO NOT remove the animation from the screen once it has ended IF the narration for that segment is in progress.

**SPATIAL REASONING PROTOCOL**

Before placing any object, you MUST think through spatial conflicts to prevent overlaps.

**Core Principles:**

1. **Track Vertical Positions Explicitly**
   - Note exact y-coordinates for positioned objects (`move_to(UP*2)` means y=+2)
   - Calculate `next_to()` placements: object placed `next_to(ref, DOWN)` typically sits 0.5-1.0 units below reference
   - Text with font_size=28 has height ≈ 0.5-0.7 units

2. **Calculate Bounding Boxes**
   - Circles: center ± radius in all directions
   - Rectangles: center ± (width/2, height/2)
   - Text/MathTex: typically 0.5-1.0 units tall, variable width

3. **Overlap Detection Before Placement**
   - If |y_posA - y_posB| < (height_A/2 + height_B/2 + buffer), objects will overlap
   - Maintain minimum buffer of 0.5-1.0 units between unrelated objects

4. **Vertical Zone Allocation**
   - Title zone: y > +2.5 (top edge)
   - Upper content: y = +1.0 to +2.0
   - Middle content: y = -1.0 to +1.0
   - Lower content: y < -1.0
   - Leave entire zones empty between conceptually separate elements

5. **Mental Checklist Before Adding Objects**
   - List all currently visible objects and their y-positions
   - Calculate new object's bounding box
   - Check: does it intersect any existing object?
   - If yes: adjust position, remove old objects first, or move to different zone

**FIDELITY TO SPECIFICATION**

- Shapes: Create exactly what's specified in `scene.shapes` list
- Animations: Execute exactly what's in `scene.animations` list
- Math animations: Implement all items in `scene.math_animations` list

### Code Generation Pattern with Phase Tracking

```python
def construct(self):
    # Title (persists across phases)
    title = Text("Scene Title", font_size=36).to_edge(UP)
    self.play(Write(title), run_time=1.5)
    self.wait(1)

    # ===== PHASE 1: Opening Hook/Intuition =====
    phase_1_objects = []

    visual1 = Circle(radius=1.5, color=BLUE).move_to(UP * 1)
    label1 = Text("Core concept", font_size=28).next_to(visual1, DOWN)
    phase_1_objects.extend([visual1, label1])

    self.play(Create(visual1), Write(label1), run_time=2.0)
    self.wait(1.5)

    # CLEANUP PHASE 1
    self.play(*[FadeOut(obj) for obj in phase_1_objects], run_time=1.5)
    self.wait(0.5)

    # ===== PHASE 2: Technical/Mathematical =====
    phase_2_objects = []

    equation = MathTex(r"E = mc^2").move_to(UP * 2)
    eq_label = Text("Equation explanation", font_size=24).next_to(equation, DOWN)
    phase_2_objects.extend([equation, eq_label])

    self.play(Write(equation), FadeIn(eq_label), run_time=2.0)
    self.wait(2.0)

    # CLEANUP PHASE 2
    self.play(*[FadeOut(obj) for obj in phase_2_objects], run_time=1.5)

    # Final cleanup
    self.play(FadeOut(title), run_time=1.0)
    self.wait(1)
```

## Position Mapping Reference

**Common position strings map to Manim coordinates:**
- "center" → ORIGIN
- "left" → LEFT * 3 or LEFT * 2
- "center_left" → LEFT * 1.5
- "right" → RIGHT * 3 or RIGHT * 2
- "center_right" → RIGHT * 1.5
- "top" → UP * 2 or UP * 3
- "top_left" → UP * 2 + LEFT * 3
- "top_right" → UP * 2 + RIGHT * 3
- "bottom" → DOWN * 2
- "above" / "below" → Use `.next_to(ref_shape, UP/DOWN, buff=0.5)`

**Avoid overlaps:**
- If equation/title at "top", don't put diagram at "top" too
- Use different vertical OR horizontal positions for multiple shapes
- Use `.next_to()` with appropriate `buff` for spacing

## Color Mapping Reference

Common colors in Manim (check examples for exact usage):
- WHITE, BLACK, GRAY, LIGHT_GRAY, DARK_GRAY
- RED, GREEN, BLUE, YELLOW, ORANGE, PURPLE, PINK
- Use color constants directly (e.g., `color=BLUE` not `color="blue"`)

**BEFORE writing code like this, you MUST think through spatial positioning:**

I need to place multiple objects in this scene. Let me track positions to avoid overlaps:

Step 1 - Title:
- title uses .to_edge(UP), which places it at y ≈ +3.5
- Height ≈ 0.6 units (font_size=36)
- Occupies vertical zone: y = +3.2 to +3.8
- Status: Title zone reserved

Step 2 - Main content planning:
- equation at UP * 2 → y = +2.0
- MathTex height ≈ 0.5 units → occupies y = +1.75 to +2.25
- eq_label uses next_to(equation, DOWN) → places it roughly 0.5 units below
- eq_label at y ≈ +1.3, height ≈ 0.5 units (font_size=28)
- eq_label occupies: y = +1.05 to +1.55

Now for the diagram (Circle with radius=1.5):
- If I place at ORIGIN (y=0): extends from y = -1.5 to y = +1.5
- Top of circle (y = +1.5) would OVERLAP with eq_label (y ≈ +1.05 to +1.55)
- CONFLICT DETECTED: |1.5 - 1.3| = 0.2, which is < (1.5 + 0.25 + 0.5 buffer)

Solution: Move circle to DOWN * 1.5 → y = -1.5
- Circle now extends from y = -3.0 to y = 0.0
- diagram_label below circle at y ≈ -3.5
- Clear separation: gap between eq_label bottom (+1.05) and circle top (0.0) = 1.05 units ✓

Current layout after Step 2:

y = +2.0: [equation - MathTex]
y = +1.3: [eq_label - Text]
y = -1.5: [diagram - Circle, radius 1.5, extends to y=0.0]

All objects have proper spacing ✓

## CRITICAL: Temporal Overlap Prevention

**The #1 animation quality issue is TEMPORAL OVERLAP - showing new content before clearing old content.**

### Before Writing ANY `self.play()` Call

Ask yourself these questions:

<thinking>
1. What objects are currently visible on screen?
2. Is the new content conceptually different from what's visible?
3. If yes → MUST FadeOut old content first
4. If no → Can build on existing content
</thinking>

### Mandatory Phases Pattern

Structure your construct() method into CLEAR PHASES separated by cleanup:

```python
def construct(self):
    # PHASE 1: Setup
    title = Text(...)
    self.play(Write(title))
    self.wait(1)

    # PHASE 2: First concept
    diagram1 = ...
    self.play(Create(diagram1))
    self.wait(1.5)

    # CLEANUP BEFORE PHASE 3 - MANDATORY!
    self.play(FadeOut(diagram1), run_time=1.5)

    # PHASE 3: Second concept (FRESH CANVAS)
    diagram2 = ...
    self.play(Create(diagram2))
    self.wait(1.5)

    # CLEANUP BEFORE PHASE 4
    self.play(FadeOut(diagram2), run_time=1.5)

    # Final cleanup
    self.play(FadeOut(title), run_time=1.0)
```

### Rules for When to Clear

✓ **MUST FadeOut when transitioning between**:
- Different diagrams (architecture → heatmap → flowchart)
- Different equations (unless building on previous)
- Different examples (sentence A → sentence B)
- Intuitive explanation → technical explanation
- Any conceptual shift in narration

✗ **Can keep visible when**:
- Adding labels to existing elements
- Highlighting/indicating existing elements
- Small additions that complement (not replace) current content

### Anti-Pattern Example (NEVER DO THIS)

```python
# Creates encoder diagram
self.play(FadeIn(encoder_layers))  # Many boxes visible
self.wait(1)

# Creates text WITHOUT clearing diagram first ❌ WRONG!
german_text = Text("Das Gesetz...").move_to(DOWN*0.5)
self.play(Write(german_text))  # NOW OVERLAPPING!

# Too late to cleanup
self.play(FadeOut(encoder_layers), FadeOut(german_text))
```

### Correct Pattern (DO THIS)

```python
# Creates encoder diagram
self.play(FadeIn(encoder_layers))
self.wait(1.5)

# CLEAR FIRST ✓
self.play(FadeOut(encoder_layers), run_time=1.5)
self.wait(0.5)  # Brief pause for clean transition

# NOW show text on clean canvas
german_text = Text("Das Gesetz...").move_to(DOWN*0.5)
self.play(Write(german_text))
self.wait(2.0)
```
