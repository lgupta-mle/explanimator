## Codebase Patterns
- Config lives in `src/research_viz/config/pipeline_config.py`; use `get_config()` singleton accessor
- YAML config at project root `config.yaml`; env overrides via `ANVAYA_*` prefix with `__` nesting (e.g. `ANVAYA_LLM__EXPLANATION_MODEL`)
- Use `reset_config()` in tests to clear singleton state
- Tests go in `tests/` directory; run with `python3 -m pytest tests/ -v`
- Project uses pydantic for schemas, pydantic-settings for config
- LLM calls go through OpenRouter (prefix models with provider e.g. `openai/gpt-5`)
- Hardcoded model names scattered across: `pdf_explanation_generator.py`, `pdf_to_manim_pipeline.py`, `llm_utils.py`, `beat_sync_tts.py`
